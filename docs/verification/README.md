# Resultados locales conservados

Archivos producidos por ejecuciones reales del 14 de noviembre de 2026. Los `.txt` son resúmenes Surefire/Failsafe; el log completo corresponde a Java 21 en Docker. `runtime-verification.json` registra comprobaciones HTTP y persistencia después de reiniciar.

Esta carpeta conserva las pruebas locales. Las capturas de AWS se guardan por separado. Para repetir las pruebas, seguir ../testing.md. Los resultados incluyen identificadores y rutas de pruebas locales, sin contraseñas del proyecto.
